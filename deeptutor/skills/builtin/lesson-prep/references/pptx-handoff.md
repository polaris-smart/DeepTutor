# lesson-prep → pptx 交接协议

在老师确认教案并选择生成课件后读取本文件。它只定义输入、图片路径、版式和验收边界；具体创建命令与实现始终以仓库内官方 `deeptutor/skills/builtin/pptx/SKILL.md` 为准。

## 1. 强制交接顺序

1. 固定当前“已确认教案”的版本，停止使用确认前的草稿。
2. 调用 `read_skill(name="pptx", file="SKILL.md")`，完整读取官方 `deeptutor/skills/builtin/pptx/SKILL.md`；不要只凭既有的 `python-pptx` 经验生成。该调用不可用但 sandbox 能访问仓库时，直接读取上述路径的全文；两种方式都不可用时停止生成并说明缺失项。
3. 按下方协议整理内容和图片路径。
4. 使用官方 skill 指定的 sandbox / `python-pptx` 流程创建课件，明确设置 `prs.slide_width = Inches(13.333)`、`prs.slide_height = Inches(7.5)`，再保存、重新打开并验证。
5. 返回执行工具产生的 artifact 下载链接；不要只回复文件系统路径。

若 `pptx` skill 不可用或 sandbox 缺失，说明具体缺失项并保留已确认教案，不生成伪链接。

## 2. 输入契约

交接时准备以下字段；缺失项显式置空并说明，不自行补造：

| 字段 | 要求 |
| --- | --- |
| `lesson_title` | 已确认课名 |
| `subject` / `grade` | 学科与年级 |
| `textbook` | 已锁定的教材文件名或标题 |
| `struct_path` | 教材树中的原始路径 |
| `duration_minutes` | 教案总时长 |
| `confirmed_lesson_plan` | 主剧本第五步经老师确认并固定的完整教案，而非确认前草稿 |
| `knowledge_points` | 有序知识点；每项含标题、要点、例题和来源节点 |
| `linked_images` | 从课内节点去重后的图片清单；每项含原始路径、`node_id`、`struct_path`、插入环节和教学目的 |
| `homework` | 基础、提升、拓展作业 |
| `output_name` | 含课名且以 `.pptx` 结尾的新文件名 |

## 3. 图片路径契约

1. 从接口响应的节点或 `metadata.linked_images` 取得路径，原样放入交接对象的 `linked_images`；不要改名、猜扩展名或把相对路径伪装成绝对路径。每条路径与来源 `node_id`、`struct_path`、教学环节和教学目的绑定传递，避免脱离教材上下文。
2. 在 sandbox 中逐条确认路径存在、可读且确为支持的图片格式，再把经过验证的真实路径传给 `slide.shapes.add_picture(...)`。
3. 对相对路径，只能依据当前工作区或已挂载来源提供的真实根目录解析；根目录未知时请求补充或降级。
4. 路径不可访问、格式不支持或图片损坏时，跳过该图片，在对应页放置简洁文字占位，写明原始路径与预期教学用途，并在交付说明中列出。
5. 保持图片纵横比，避免拉伸；裁切时保留教材中的关键标注。不要联网下载“相似图片”替代课内图片。

## 4. 16:9 尺寸与版式

- 使用标准宽屏 16:9：宽 `13.333 in`，高 `7.5 in`。不要使用默认 4:3。
- 保持至少 `0.5 in` 页边距；正文左对齐，控制每页信息密度。
- 按以下顺序组织：

  1. 封面：课名 + 学科，可补教材与年级。
  2. 教学目标：集中 1 页，保持教案中的 3 条目标。
  3. 知识点页：每个知识点 1–2 页，至少包含标题、关键要点、概念关系和教材来源；内容过多时拆页，不缩成不可读小字。
  4. 例题页：将已确认教案选定的重点例题单独成页，呈现题面、来源、思路或关键步骤和课堂任务；题面不完整时保留 `[待补素材]`，不续写。
  5. 图表页：按教学顺序使用已验证的 `linked_images` 插图，配观察任务或讲解提示；无可用图片时保留文字占位或按教案说明省略独立图表页，不虚构图片。
  6. 作业页：呈现基础、提升及可选拓展任务，并保持教材题与 `[模型设计]` 题的来源标记。

不要机械重复同一版式。具体字体、字号、配色、图片插入、导出与视觉检查规则服从刚读取的官方 `pptx` skill。

## 5. 交付验收

1. 用 `Presentation(output_name)` 重新打开文件，确认文件未损坏。
2. 核对封面课名和学科、3 条目标、每个知识点页、例题页、图表页和作业页均与已确认教案一致。
3. 检查课件尺寸确为 16:9，并搜索残留占位文本。
4. 环境有 LibreOffice / PDF 图片转换工具时，按官方 skill 渲染并逐页检查溢出、遮挡、低对比度和图片变形；工具缺失时明确跳过，不自行安装。
5. 最终返回 `.pptx` artifact 下载链接，并附上未插入图片或其他降级项。
