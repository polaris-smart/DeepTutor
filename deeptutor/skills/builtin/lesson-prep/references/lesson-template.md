# 中文教案输出模板

按以下顺序输出。默认一课时为 45 分钟；若老师指定其他时长，调整各环节并保证总和一致。花括号中的内容应替换为实际结果，不要把占位符原样留在最终教案中；最终教案直接渲染为 Markdown，不要包在代码围栏中。

| --- | --- |
| 知识库 | {kb_name} |
| 教材 | {file_name} |

## 输出检查

输出前逐项检查：

- 教学目标恰好 3 条，动词可观察，且能在课堂环节中找到对应活动。
- 环节顺序为“导入 → 讲解 → 例题 → 练习 → 小结”，时长合计等于总课时。
- 知识点来自节点标题、小节或正文摘要，并附可追溯依据。
- 课内题优先于自拟题；选择类用于热身，解答类用于重点讲解或练习。
- 每个 `linked_images` 都有具体使用环节；接口未返回时明确缺失。
- 板书能看出本课逻辑主线，作业至少有基础与提升两层。
- 教材来源、保守推断、模型设计和待补素材没有混写。
