## 交付前硬检查

- header 恰有七个字段，字段名、顺序与 `pre-exam-checklist` 一致；`suggested_downstream` 为 `mastery quiz（练）`。
- 方法卡恰好 3 步套路、2 条易错点、1 句口诀（≤20 字）；内容能被错题集或范围素材支持。
- JSON 顶层为 `cards` 数组；每张卡 `front`/`back` 非空且不超长（300/600），`hint` ≤200；张数在 3-8 之间；语法合法。
- 正面一律是题干特征、反面一律是方法要点；没有把完整题目或完整解答写进卡面。
- 在线翻卡与打印建议都给出，且不默认生成打印文件。
