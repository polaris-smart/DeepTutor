# 考前抢分清单器

把教材证据压缩成一张 10-15 分钟能扫完的 A4 清单。只整理当前考试范围，不凭常识补写教材事实；宁可说明素材不足，也不要交付一份看似完整但无法追溯的清单。

开始后依次执行下面五步。先调用 `read_skill(name="pre-exam-checklist", file="references/api-guide.md")`；提纯前读取 `references/template.md`；生成 HTML 前读取 `references/print-css.md`。

## 第一步：识别考试范围

1. 从用户表达中提取学科、教材、考试范围和受众。例如“下周考数学第三章”解析为学科、教材上下文与章级范围；“X 月 X 日考《XX》第 N 单元”保留明确日期和单元名。
2. 判断版本：
   - 用户以学生身份描述自己的考试或复习任务，生成学生版；仅在当前回合确有 mastery path 时追加薄弱点标记。
   - 老师直接给出教材和单元、提到“全班/发给学生/通用版”时，生成通用版，不读取、不混入任何个人 mastery。
3. 使用当前会话选中的 `kb_name`。教材或范围不能唯一确定时，先按 API 指南调用 `textbook-tree` 取得真实教材结构，再只问一次；把最接近的教材和完整结构路径列成可选项，不用模型自造目录。
4. 如果知识库也缺失，把知识库与范围合并在同一个问题里询问，不拆成多轮追问。一次回答后仍无法定位时停止并说明缺失项，不猜路径。
5. 用 `by-struct` 验证候选 `struct_path`，并以选中教材的 `file_name` 过滤。锁定 `kb_name`、学科、教材、单元、受众和最终路径后再继续。

## 第二步：收集弹药

这一步自动进行，不等待用户确认。

1. 调用 `GET /api/v1/knowledge/{kb_name}/docs/by-struct?path={struct_path}&limit=100`，取得范围节点。
2. 若范围下有多课，除范围级请求外，再按教材树中的每个直接课级子路径请求一次；合并后按 `node_id` 去重，并始终按 `file_name` 过滤，尽量覆盖直接挂在单元与课下的节点。
3. 按实际响应采集正文/摘要、题目和结构元数据：优先使用 `content` 或 `text`，只有 `preview` 时把它当摘要；题目字段仅在响应确实返回 `is_question`、`q_id`、`q_type`、`has_answer` 时使用。
4. 任一请求恰好返回 100 个节点时视为可能截断。继续尝试更具体的课级/小节路径；仍达到上限时，在结果中明确披露，绝不声称“已取得全部原文”。
5. 学生版且 `mastery_status` 工具已挂载时，无参数调用一次：
   - 只把 `map.modules[].knowledge_points[]` 中 `status: learning`、且名称与当前范围节点明确对应的项目视为薄弱点；
   - `new` 只代表尚未学习，不冒充“做错过”；`mastered` 不标为薄弱；
   - 仅用 `🔥` 提升对应清单项的排序或醒目度，不让 mastery 数据替代教材事实。
6. 没有 active mastery path、工具不可用或映射不确定时直接做通用内容，不创建 mastery path，不猜学生弱项。

## 第三步：提纯成清单

`references/template.md` 是输出合同。违反任一条都必须重写后再交付：

1. 按课分节；每课固定为“🎯 必背核心考点”和“⚠️ 易错易混点”两栏。
2. 每课核心考点必须有 5-8 条。每条是“主语/标签 + 关键事实”的编号短句，最多含一个加粗关键词；按可见字符计数，每条不超过 40 个汉字/字符，不计序号和 Markdown 的 `**` 标记。
3. 每课易错点必须有 2-4 条，每条逐字遵循：`❌ <常见错误说法>，<正确说法>（<辨析钩子>）`。不改成问句、口诀或普通解释句。
4. 先在内部建立“最终短句 → `node_id` / `struct_path` / 原文片段”的证据表。数字、年份、人名、条约名必须从已检索节点逐字摘取并保持一致；不凭记忆校正、补全或引入课外说法。
5. 易错点的正确部分必须能由节点证明；错误部分只能由同一组教材事实做反向混淆，不编造另一条外部史实充当对照。
6. 节点不足以支撑某课至少 5 条核心考点或 2 条易错点时，不用空话凑数。说明缺少的教材证据，请用户补充材料或修复知识库后再生成合同版。
7. 输出前逐项计数、逐句验长、逐个核对专名和数字。学生薄弱标记不改变原事实，也不额外增加加粗词。

## 第四步：三格式输出

1. 先在聊天中给出完整 Markdown 预览。头部、双栏、每课条数、结尾钩子均不得省略。
2. 将同一份已核验内容转换为独立 HTML，不再次改写事实。把 `references/print-css.md` 的 CSS 完整内嵌到 `<style>`，使用语义化的 `.sheet`、`.lesson-list`、`.lesson`、`.lesson-grid`、`.core-panel` 和 `.mistake-panel` 结构。
3. 必须调用 `exec` 把 HTML 写进当前回合工作目录，不能只在聊天中贴代码或声称文件已生成。可使用标准库完成一次性写入，例如：

   ```text
   python - <<'PY'
   from pathlib import Path
   html = r'''<!doctype html>...完整 HTML...'''
   path = Path("pre-exam-checklist-YYYYMMDD.html")
   path.write_text(html, encoding="utf-8")
   text = path.read_text(encoding="utf-8")
   assert "@media print" in text and "A4 portrait" in text
   print(path)
   PY
   ```

4. 从 `exec` 返回结果中取该 `.html` 的 Generated artifacts URL，作为 A4 打印版下载链接；不要只返回沙箱路径。若文件名已存在，写入带日期或短范围名的新文件，不覆盖用户已有文件。
5. 渲染工具可用时，可从同一 HTML 额外导出 PDF，并返回 PDF artifact；不可用时跳过 PDF，不阻塞 Markdown 和 HTML，也不伪造链接。

## 第五步：接力钩子

1. Markdown 和 HTML 源码最前面都放置模板中的标准 `deeptutor_handoff` 注释块。字段必须完整：学科、教材、范围、学生或“通用”、日期、上游 mastery 状态、建议下游“题感训练”。
2. 标题固定为 `📝 《教材名》《单元名》考前抢分清单`，随后给出适用场景行和核心原则行：`抓主干、排陷阱、背框架`。
3. 结尾原样提示：`要配套的同范围练习 → 说“来一组”`。这只是接力提示；用户未明确说“来一组”前，不自动生成练习或调用下游 Skill。

## 异常与降级

- 教材树为空或路径查询为空：展示真实返回结果和候选路径，停止编造内容。
- 只有 `preview`：可以基于可见摘要提纯，但要注明证据受 200 字预览限制；被截断的年份、专名或句子不得补全。
- 认证或权限错误：保留状态码和 `detail`，请用户重新登录、换知识库或申请权限，不反复盲目重试。
- `exec` 不可用：仍可给 Markdown，并明确 HTML 文件未生成；不要把聊天代码块冒充下载文件。
- 用户要求压缩到少于合同条数：解释合同版每课仍需 5-8 条核心和 2-4 条易错；可以另给口袋版，但不能替代合同版。
