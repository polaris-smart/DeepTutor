## A4 HTML 映射

- 整页使用 `.sheet`；标题使用 `.title`；封面信息使用 `.lead`。
- 三个部分放入 `.lesson-list`，每部分使用一个 `.lesson`。
- 诊断与矩阵的摘要卡使用 `.lesson-grid`；事实卡用 `.core-panel`，提醒与缺口用 `.mistake-panel`。
- 每条补弱动作使用 `.unit-frame`，并保持整卡 `break-inside: avoid`。
- 先完整嵌入 `pre-exam-checklist/references/print-css.md`，再追加表格横向滚动、表头底色和报告页脚等少量样式；不要复制后删减原骨架。

## 交付前硬检查

- Markdown 与 HTML 的 header 七字段逐字一致，`suggested_downstream` 为“全开放”。
- 封面 + 第一部分诊断 + 第二部分矩阵 + 第三部分补弱清单全部存在。
- 总分、得分、丢分及所有分布表与上游一致；矩阵没有被重新估算。
- 每条完整补弱动作恰有 3 个真实 `q_id`；不满 3 个时明确写待补数量，没有假 ID。
- HTML 含完整 CSS 骨架、`A4 portrait`、`@media print`、UTF-8 和视口元数据。
- 两个文件均由 `exec` 实际写出并返回 artifact；PDF 失败不影响 Markdown 与 HTML。
